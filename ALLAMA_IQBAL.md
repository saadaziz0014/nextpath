# Allama Iqbal Express — route research and simulation profile

Researched 2026-10-08. This is a simulated journey, not an official live timetable.

## Findings and sources

- Pakistan's government news agency APP identifies Allama Iqbal Express as Karachi–Sialkot–Karachi, 9 Up / 10 Down: https://www.app.com.pk/national/railways-announces-temporary-stops-for-trains-at-different-stations/
- Up stop profile (37 stops): https://tracktrain.pk/trains/allama-iqbal-express-9up
- Down stop profile (36 stops, excluding Gambat): https://tracktrain.pk/trains/allama-iqbal-express-10dn
- Cross-check of corridor and branch: https://railwaystations.pk/search-by-train/9up-allama-iqbal-express/
- Official timetable entry: https://pakrail.gov.pk/traintiming.aspx . Its train/date form did not expose a current stop table in the retrieved page. Published secondary sources disagree on some stops; these profiles are explicitly a simulation snapshot, not certified current operating information.

The route follows Karachi Cantt → Rohri → Bahawalpur → Lodhran → Dunyapur → Jahanian → Khanewal → Raiwind → Lahore → Shahdara → Narang → Baddomalhi → Narowal → Pasrur → Chawinda → Sialkot. It uses the chord, bypassing Multan, and the Narowal branch rather than Wazirabad. The APP announcement's Dera Nawab Sahib stop was a three-month trial; without confirmation of continuation it is not added as a scheduled stop. No departure times, live positions or automatic station stops are claimed.

## Implementation

`lib/rail/trains.ts` contains a typed train catalogue with separately defined services and stop profiles. Track geometry is independent of service definitions. `servicePath` checks every scheduled stop maps exactly once to a sourced station and appears in travel order, before the dataset enters the browser.

A continuous canonical Karachi–Sialkot track is generated by the importer from exact OSM node connections with ordered corridor anchors. Down reverses this geometry but uses its own stop list. The imported geometry measures approximately 1,362.73 km; this is computed geometry length, not an official railway mileage.

Missing Narowal–Sialkot source geometry is saved in `data/rail/allama-iqbal-narowal-sialkot.osm.json`, with the source timestamp in the generated dataset manifest. `node scripts/fetch-allama-iqbal.mjs` refreshes the public Overpass extract. Station aliases for Narowal and Baddomalhi translate the existing OSM station IDs; no station positions or tracks are invented. Newer overlapping data retains older translated names/centres when omitted.

Run `npm run rail:import`, then `npm run rail:verify`. Import rejects loops, retracing and abrupt reversals before replacing the browser dataset. Verification checks every output segment against an original OSM rail segment to within 1 cm. OSM data: © OpenStreetMap contributors, ODbL 1.0.

## Controls

Rail mode opens with train selection. Select Allama Iqbal Express, then 1 for 9 Up or 2 for 10 Down (buttons also work). Choose any departure stop except that service's final destination. Direction is fixed by service. W accelerates, S brakes manually, release coasts, Space pauses; maximum speed remains 90 km/h. Starting-station edits lock once moving. Reset returns to that departure and unlocks edits. Change route returns to the train picker. Explore tracks retains the previous generic itineraries and bidirectional station departures.
